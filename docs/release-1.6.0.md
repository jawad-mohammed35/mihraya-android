# Mihraya 1.6.0 — Offline Hadith and refreshed navigation

This release adds a locally searchable Hadith reader and reorganizes Home navigation while retaining the existing Quran, audio, prayer, Qibla, settings and Tasbih stores.

## Navigation and reading

- Bottom tabs: **Home · Quran · Listen · Hadith · Tasbih**, with the existing sliding Liquid Glass lens and filled selected icons.
- More/settings now opens from Home's upper-right button; Qibla sits beside the location.
- Hadith collection/section browsing, search, reading anchors, separate persistent bookmarks, clipboard copy, Android sharing, adjustable Arabic/translation sizes and a database-backed Random Hadith action.
- Arabic/English content works offline immediately. Optional translations download by collection with size/progress, digest/structure verification, transactional installation, retries, removal and English fallback.
- Existing theme, OLED Black and accent settings apply throughout. No Daily Hadith Home card was added.

## Included source editions

- **An-Nawawi's Forty Hadith: 42 records**, Arabic and English bundled. French, Turkish and Bengali downloads.
- **Forty Hadith Qudsi: 40 records**, Arabic and English bundled. French download.
- **Shah Waliullah's Forty Hadith: 40 records**, Arabic and English bundled. French download.

These 122 records include every record in the selected upstream editions. IDs, Arabic/translation references, numbering, section counts, nonempty text and replacement-character checks were performed for all included records. This is **not a claim of scholarly textual verification or canonical completeness across all editions**. Source numbering and edition information are shown in each reader. No text, translation, grading, narrator or missing chain is generated by Mihraya.

**Bukhari, Muslim, Tirmidhi, Abu Dawud, Nasa'i, Ibn Majah and Muwatta are not included**: their inspected Arabic editions contain damaged Unicode characters, with blank records also present in the dataset. The audit preserves the affected source IDs; no speculative repairs or filtered partial collections are shipped. Riyad as-Salihin was omitted as requested because UmmahAPI does not provide it. Bulugh al-Maram is absent from that source. Urdu/Indonesian are unavailable for the included editions. Similar-Hadith links and structured isnad views are omitted because reliable structured data was unavailable.

## Validation and installation

57 JVM tests and the Android database/download integration test passed on Android 15/API 35. Lint and the signed/minified build passed. The signed update was installed over 1.5.0 without clearing data. Navigation, Qibla access, source browsing/search, bookmarks across restart, random selection, clipboard/share sheet and theme rendering were checked. See `docs/qa/1.6.0.md` for the exact checks and limits; no physical-device, older-Android or scholarly audit is claimed.

After publication, all eight public text-package downloads were independently checked against their pinned sizes/digests. The signed app's real French download, language switching, cold offline reading, removal and English fallback were also verified. The existing Quran bookmark remained present.

Install **Mihraya-1.6.0.apk** over your existing app. It uses the existing signing key. The JSONL attachments are checksum-pinned offline text/translation packages used by the app; they do not need to be installed manually. Previous releases are preserved.
