# Mihraya

Prayer times, Quran, recitation, Hadith, Qibla, Tasbih, Zakat and the 99 Names of Allah for Android. The floating Liquid Glass bar blurs scrolling content on supported devices. Tap a tab or slide across the bar and release to switch sections. A moving lens previews your selection.

## Features

- **Hadith library**: 10 source collections with 40,587 Arabic records available. Nawawi's Forty (42), Forty Hadith Qudsi (40), and Shah Waliullah's Forty (40) remain bundled. Download Bukhari (7,276), Muslim (7,564), Tirmidhi (3,956), Abu Dawud (5,274), Ibn Majah (4,341), Nasa'i (5,761), and Mishkat (6,293) as compressed offline packages. Browse source chapters, search indexed local text, continue reading, bookmark separately from Quran, copy/share, adjust font sizes, or open a random narration. Downloads show size/progress, validate SHA-256 and structure before a transactional install, retry interruptions, and can be removed without losing bookmarks.
- **Navigation**: Home, Quran, Listen, Hadith, Tasbih. More and settings open from Home's upper-right button; Qibla sits beside the location. The existing moving glass lens, accent colors, and tab state restoration remain in use.

### Hadith coverage and accuracy

The three original collections use the pinned [Fawaz Ahmed Hadith API edition](https://github.com/fawazahmed0/hadith-api/tree/df57907be35291c91ad6a6691180e22ca9920784) declared by UmmahAPI. The seven additions use an authenticated November 17, 2026 [HadithAPI.com](https://hadithapi.com/) snapshot. All reported source IDs, chapter membership/counts, source numbering and Arabic records were checked; no damaged/missing Arabic records were found in the seven new snapshots. Chapter zero, Arabic titles, source headings and narrator fields are retained. API status labels are attributed to the provider; named grading scholars are not supplied, and recognized collections are not blanket-labelled authentic by Mihraya. These are source/structural checks, **not scholarly verification or proof of canonical completeness across print editions**.

**Translation coverage:** Bukhari has English for 7,274/7,276 records; Tirmidhi for 3,949/3,956; Nasa'i for 5,759/5,761. The missing translations are explicitly marked unavailable; the Arabic narrations are retained without fabricated English. Muslim, Abu Dawud and Ibn Majah have English for every reported record. **Mishkat is Arabic-only in the default package; this provider supplies no English for it.** Complete Urdu editions are downloadable for Bukhari, Muslim, Abu Dawud, Ibn Majah, Nasa'i and Mishkat. Tirmidhi's Urdu edition is not offered because one translation is missing. Nawawi retains French/Turkish/Bengali, and Qudsi/Dehlawi retain French. No translation is generated by Mihraya.

**Not added:** Musnad Ahmad and Al-Silsila Sahiha report zero Hadith through this API; Muwatta, Darimi, Riyad, Bulugh and Al-Adab al-Mufrad are not offered by it. Previously rejected damaged Arabic editions were not repaired or mixed speculatively with this new source. Similar-Hadith links and structured isnad graphs remain absent where verified relationship data is unavailable.

The original repository declares The Unlicense, without independently clearing translator/publisher rights. HadithAPI describes its service as free; explicit public bulk/offline redistribution terms and request-rate limits were not located. The owner authorized offline use after reviewing that statement; no independent content-rights clearance is claimed. See [NOTICE](NOTICE), the [original source audit](docs/hadith-source-audit.json), [HadithAPI audit](docs/hadithapi-audit.json), and [package instructions](docs/hadith-data.md). The API credential is used only by a local import tool, stays in an ignored file/environment variable, and is never part of the Android app, static packages, logs, or Git history. No backend secret or API key is required on the phone.

### Other features

- **Prayer times** calculated on the device, with Adhan or tone alerts, a day and month timetable, and Hijri dates.
- **Quran reader** with offline Uthmani and QuranWBW IndoPak Madinah editions. New installations start with IndoPak; existing script preferences are retained. IndoPak uses its matching typeface, pause marks, and verse markers. Switch scripts while keeping your translations, bookmarks, and reading position. Landscape reading uses the available width, with Reading Preferences in a sliding right-side panel; portrait keeps its bottom sheet. Amiri Quran preserves its original shaping with room for stacked marks. The reader also supports transliteration, search, and optional Uthmani tajweed colors.
- **Recitation** from 17 reciters, streamed or downloaded for offline listening, with background playback.
- **Qibla** compass and a **Tasbih** counter with presets, custom dhikr, and history.
- **Home screen widgets** for prayer times, the next prayer, Qibla, verse of the day, last read, bookmarks, audio, and Tasbih. Choose Dark, Light, Transparent, or System separately for each widget. System follows Android’s day/night appearance and honors OLED Black at night. The Bookmarks widget adapts to its exact size, scrolls through saved verses, and offers a shortcut for Surah, Ayah, and Juz navigation.
- **App shortcuts**: long-press the Mihraya icon to open Quran, Listen, or Tasbih directly, or drag a shortcut onto the home screen.
- **Appearance**: Black, Light, or System theme, an optional OLED Black mode, and four accent colors.

### Zakat Calculator

The annual estimate displays the calculated amount at the top. The introductory paragraph and visible Guidance & Sources card have been removed; necessary assumption notes remain beside the relevant controls, and attribution remains in About.

Open **More → Zakat Calculator** to estimate annual Zakat with a detailed assets,
short-term deductions, net wealth, Nisab and amount-due breakdown. Choose gold
(87.48 g) or silver (612.36 g) Nisab and explicitly confirm the relevant lunar-year
Hawl. Calculations use decimal arithmetic and a 2.5% rate, with due rounded to two
decimal places. Negative net wealth is floored at zero; missing/invalid required
prices prevent an estimate.

Enter cash, bank savings, eligible investment portions, trade inventory,
recoverable receivables, other eligible assets, and gold/silver weights in grams,
troy ounces or tola. Gold supports 18/21/22/24 karat; silver uses fine-metal
weights. Personal-use jewelry can be included/excluded according to the guidance
you follow. Investment portions and short-term deductions are user-assessed;
the tool does not automatically deduct entire long-term debts or determine
asset-specific fiqh/Hawl rules. Consult a qualified scholar for your circumstances.
Guidance: [Islamic Relief](https://islamic-relief.org/zakat-faq/).

USD defaults to manual prices, with an explicit **Refresh market quotes** action
using [Gold API](https://gold-api.com/docs). Each quote shows its source and
provider timestamp, converted from USD/troy ounce using 31.1034768 grams. Quotes
older than 24 hours are marked dated; no quote is described as streaming/live.
Network failure retains the existing values and offers manual entry. EUR, GBP,
CAD, INR, SAR and AED support manual prices; changing currency clears the draft
after confirmation instead of silently converting monetary inputs.

Save/load one calculation on the device, reset the draft, and copy/share a
summary with prices, timestamps, assumptions and disclaimer. Nisab/currency
preferences persist separately. The new shared-preferences file is independent
of existing user data and excluded from Android cloud backup because it can
contain financial amounts. Android 12+ device transfer can retain it. No asset
amounts are sent to the price provider.

### 99 Names of Allah

Open **More → 99 Names of Allah** for the complete offline list with Arabic,
transliteration, concise English meanings, normalized search, and centered
copy/share dialogs. Choose **Amiri**, **Nastaliq** (Noto Nastaliq Urdu, a South Asian style), or **Noto Naskh** from the page's Arabic font selector. The choice persists and applies to the list, popup and learning games. The existing Unicode Arabic Names are unchanged; no Quran script dataset or special Quran font encoding is substituted. All three already-bundled fonts use SIL OFL 1.1. Nastaliq receives additional line spacing and font padding for its taller marks; RTL direction and normal weight are explicit. The source subtitle beneath Learn is removed, with attribution retained in About and shared text. The dataset is from
[my-prayers/muslim-data](https://github.com/my-prayers/muslim-data-flutter),
Copyright 2025 Kosrat Dlshad Ahmed, Apache 2.0. This established enumeration starts
with Allah and does not separately enumerate Al-Ahad. Scholarly lists and English
renderings differ; the app identifies its source and makes no claim of exclusive
interpretation or independent scholarly review. See
[the bundled source notice](app/src/main/assets/names/NOTICE.txt) and
[original license](licenses/Names-muslim-data-Apache-2.0.txt).

**Learn** offers Arabic/meaning matching and four-choice quizzes using only the
bundled dataset. Choose 5, 10, 20, 50 or all 99 Names; Arabic → English, English →
Arabic or Mixed; and source/random order. Matching uses rounds of at most five
pairs. Feedback, progress, score/results, restarts, and preference-aware haptics
are included. Completed quizzes, best percentage, correct matches and ten
recently practiced Names are stored locally, without accounts. Active sessions
survive Android saved-state recreation; unfinished quizzes do not count as
completed. Theme surfaces and accents follow existing appearance settings.

## Install

Download the latest APK from [Releases](https://github.com/jawad-mohammed35/mihraya-android/releases). On your phone, open the file and allow your browser or file manager to install apps when Android asks. Requires Android 8 or newer.

Updates use the same signing key, so you can install a newer APK over the existing app without losing your settings.

## Build

Requirements: Android Studio (or JDK 17 and the Android SDK with API 35).

Open the project in Android Studio, or from this folder:

```
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

A release APK needs a `keystore.properties` file in the project root (this file is not in the repository):

```
storeFile=/path/to/mihraya-release.jks
storePassword=...
keyAlias=mihraya
keyPassword=...
```

Then run `./gradlew :app:assembleRelease`. The build refuses to sign a release with the debug key.

Debug builds use `com.mihraya.app.debug` so they can be tested beside the signed application without replacing its data. Android database/download tests run with `./gradlew :app:connectedDebugAndroidTest` and use a separate temporary data directory.
