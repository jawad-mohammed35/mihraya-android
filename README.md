# Mihraya

Prayer times, Quran, recitation, Hadith, Qibla, and Tasbih for Android. The floating Liquid Glass bar blurs scrolling content on supported devices. Tap a tab or slide across the bar and release to switch sections. A moving lens previews your selection.

## Features

- **Hadith library**: 122 Arabic/English source records bundled for offline reading: An-Nawawi's Forty (42), Forty Hadith Qudsi (40), and Shah Waliullah's Forty (40). Browse the source sections, search downloaded text, continue reading, bookmark separately from Quran, copy, share, adjust font sizes, or open a random narration. Nawawi offers French, Turkish, and Bengali downloads; Qudsi and Dehlawi offer French. Missing preferred languages fall back to English. Downloads show size/progress, verify SHA-256 and record structure before a transactional install, retry interruptions, and can be removed without losing bookmarks.
- **Navigation**: Home, Quran, Listen, Hadith, Tasbih. More and settings open from Home's upper-right button; Qibla sits beside the location. The existing moving glass lens, accent colors, and tab state restoration remain in use.

### Hadith coverage and accuracy

Hadith data uses the pinned source edition declared by [UmmahAPI](https://ummahapi.com/api/hadith/collections): [Fawaz Ahmed's Hadith API](https://github.com/fawazahmed0/hadith-api/tree/df57907be35291c91ad6a6691180e22ca9920784). All included records were checked for matching Arabic/translation IDs, source in-book references, chapter counts, nonempty text, and Unicode replacement characters. Text is preserved as supplied; no missing text, grades, narrators, or chains are generated. This is a structural/source audit, **not scholarly verification** of every narration or translation. Source numbering is shown explicitly and can differ from print editions.

**Bukhari, Muslim, Tirmidhi, Abu Dawud, Nasa'i, Ibn Majah, and Muwatta are not included**: their inspected Arabic editions contain damaged Unicode characters, and some source records are blank. We do not repair religious text by guessing, remove damaged narrations while calling a collection complete, or advertise unavailable books. Riyad as-Salihin was omitted as requested because UmmahAPI does not provide it. Bulugh al-Maram is also absent from this source. Urdu and Indonesian are not offered for the included collections. Similar-Hadith links and extracted isnad graphs are omitted because the included editions do not provide verified structured relationships or chains.

The upstream repository declares The Unlicense, but that declaration does not independently establish rights held by the translators/publishers. Offline use of this source was explicitly requested after this limitation was explained. This app does not claim independent translation-rights clearance. See [NOTICE](NOTICE), the [source audit](docs/hadith-source-audit.json), and [package maintenance instructions](docs/hadith-data.md). English and optional translations retain the upstream wording; none are machine-generated by Mihraya.

### Other features

- **Prayer times** calculated on the device, with Adhan or tone alerts, a day and month timetable, and Hijri dates.
- **Quran reader** with offline Uthmani and QuranWBW IndoPak Madinah editions. New installations start with IndoPak; existing script preferences are retained. IndoPak uses its matching typeface, pause marks, and verse markers. Switch scripts while keeping your translations, bookmarks, and reading position. Landscape reading uses the available width, with Reading Preferences in a sliding right-side panel; portrait keeps its bottom sheet. Amiri Quran preserves its original shaping with room for stacked marks. The reader also supports transliteration, search, and optional Uthmani tajweed colors.
- **Recitation** from 17 reciters, streamed or downloaded for offline listening, with background playback.
- **Qibla** compass and a **Tasbih** counter with presets, custom dhikr, and history.
- **Home screen widgets** for prayer times, the next prayer, Qibla, verse of the day, last read, bookmarks, audio, and Tasbih. Choose Dark, Light, Transparent, or System separately for each widget. System follows Android’s day/night appearance and honors OLED Black at night. The Bookmarks widget adapts to its exact size, scrolls through saved verses, and offers a shortcut for Surah, Ayah, and Juz navigation.
- **App shortcuts**: long-press the Mihraya icon to open Quran, Listen, or Tasbih directly, or drag a shortcut onto the home screen.
- **Appearance**: Black, Light, or System theme, an optional OLED Black mode, and four accent colors.

## Install

Download the latest APK from [Releases](https://github.com/jawad-mohammed35/mihraya-android/releases). On your phone, open the file and allow your browser or file manager to install apps when Android asks. Requires Android 8 or newer.

Updates use the same signing key, so you can install a newer APK over the existing app without losing your settings.

## Build

Requirements: Android Studio (or JDK 17 and the Android SDK with API 35).

Open the project in Android Studio, or from this folder:

```
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

A release APK needs a `keystore.properties` file in the project root (this file is not in the repository):

```
storeFile=/path/to/mihraya-release.jks
storePassword=...
keyAlias=mihraya
keyPassword=...
```

Then run `./gradlew :app:assembleRelease`. The build refuses to sign a release with the debug key.

Debug builds use `com.mihraya.app.debug` so they can be tested beside the signed application without replacing its data. Android database/download tests run with `./gradlew :app:connectedDebugAndroidTest` and use a separate temporary data directory.
