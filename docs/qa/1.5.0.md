# Mihraya 1.5.0 QA

Validated November 13, 2026 with a signed, minified APK on the Android 15 / API 35 x86_64 emulator. No physical device was used.

## Changes and root causes

- The reader capped verse rows and continuous paragraphs at 680 dp in every orientation. Landscape now uses the available safe width with 16 dp gutters; portrait retains its 680 dp limit and original gutters. Bismillah follows the same adaptive column. Font sizes, RTL direction, translations, Quran text and markers are retained.
- Reading Preferences reuses its existing controls and portrait bottom sheet. Landscape uses an animated physical right-side panel with a close button, Back dismissal, outside-tap dismissal, a scrollable body and safe-drawing insets. Android 15 floating-dialog sizing initially clipped its lower controls during QA; the window now has full-screen bounds and the panel applies safe insets once. The reader remains visible beside it.
- Amiri Quran Regular 1.003 is the correct bundled font. Compared its tables with the official upstream `fonts/AmiriQuran.ttf`: GDEF, GPOS, GSUB, OS/2, cmap, glyf, hhea and hmtx are byte-identical. The full files differ in other metadata. No font replacement, text rewriting, mark removal or manual mark positioning was performed.
- Amiri Quran's hhea ascent/descent span 2449 font units at 1000 units/em, exceeding the previous default 1.9x baseline spacing. Rendering now provides at least 2.45x for this font, enables font padding for outer marks, and explicitly uses normal weight and zero tracking rather than inheriting Material text tracking. Stored font-size and line-spacing preferences are not rewritten. A contextual note explains the effective spacing minimum. Close/stacked marks defined by the font remain authentic.
- IndoPak is the new-install default. The stored-settings serializer preserves explicit script choices and treats an omitted script in an existing legacy file as Uthmani. The existing DataStore default supplies IndoPak only when no stored file exists.
- Bookmarks used coarse size breakpoints, fixed rows and a capped, non-scrollable subset. The widget now uses `SizeMode.Exact`, compact rows, stable verse IDs, and Glance 1.1's native ListView collection. A minimal-height variant prioritizes the list and shortcut. All saved bookmarks are submitted to the collection.
- The widget shortcut reuses the Quran screen's Surah/search/Juz browser and the reader's existing verse-number dialog. It opens a dedicated navigation mode without the Continue Reading card. Juz choices use the existing metadata.
- QA exposed stale reader ViewModels when an external bookmark targeted a different verse while a reader was already on top. Replacing that top reader entry now supplies fresh route arguments. QA also exposed a jump to the end of a Surah when changing between verse rows and continuous paragraphs; the ViewModel now captures the visible verse before the layout changes.

## Automated checks

Command: `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease`

- 41 unit tests passed, including five new tests for new-install defaults, legacy omitted defaults, explicit preference round-trips, Amiri spacing safety, and preservation of other fonts' spacing.
- Existing Quran metadata, published IndoPak text checksum, Tajweed, settings, reciter, library and widget tests passed.
- Debug and signed/minified release builds passed. Lint: zero errors, 81 warnings, covering dependency/toolchain recommendations, widget API attributes and existing resource/API notices.
- APK signature and ZIP alignment were checked before release publication. The release uses the existing signing configuration.

## Emulator checks

- Installed over the previous signed release without uninstalling or clearing Mihraya data. Existing Uthmani selection, profile, location, accent, original bookmark and other reading preferences remained available.
- Visually inspected Amiri Quran, Scheherazade, Noto Naskh and IndoPak in portrait and landscape. At 2400 x 1080 landscape, verse text occupied x=174..2358 after the side cutout and 16 dp gutters, rather than a narrow centered column. Portrait retained its existing column.
- Checked full-width continuous text and downloaded Uthmani Tajweed coloring. Confirmed the existing translations and verse markers remained readable. Quran assets and bundled fonts were not modified.
- Checked portrait preferences, landscape right-panel opening/closing, close button, Back and outside taps, rotation while preferences were open, and scrolling to the final translation-download control. Final landscape scroll bounds ended at y=1017, above the navigation bar, with the title below the status bar.
- Checked Light, regular Black, manual OLED Black and System dark-mode panels. Settled OLED panel pixel was exactly #000000. The other modes retained their theme-specific glass surfaces.
- A controlled ADB regression check switched verse -> continuous -> verse and asserted the same verse-139 anchor each time. Also checked cold reader launch to a requested Surah/Ayah.
- Created five temporary bookmarks alongside the existing 1:2 bookmark. All six were visible at 180 x 280 dp in a native Android AppWidgetHost. At 180 x 170 dp, Android exposed a scrollable ListView and later entries became reachable. Also checked 250 x 280, 110 x 100 and the minimum 110 x 50 dp sizes; the minimum-height layout retained a readable row and shortcut.
- Checked Dark, Light, Transparent and System widget themes using existing configuration controls.
- The existing Pixel Launcher Bookmarks widget updated in place. Resized it from 3 x 3 to 2 x 3 cells and confirmed all six references remained visible. Launcher grid dimensions are launcher-specific; exact host-size checks supplement that grid check.
- Tapped native collection entries across Surahs while the app was already reading another location; verified 1:2 opened Al-Fatihah verse 2 and 2:4 opened Al-Baqarah verse 4.
- The navigation shortcut opened the reused Quran browser. Selecting Al-Baqarah and entering 255 opened 2:255. Selecting Juz 2 opened its metadata-defined start, 2:142.
- Removed the five temporary bookmarks through Mihraya. Returned to the existing QA host without restarting it and verified the collection automatically reduced to the original 1:2 bookmark. Restored the original script/font/layout/Tajweed and appearance preferences used before those checks. Temporary QA host/snapshot packages were removed after verification.
- No Mihraya crash appeared in the emulator crash buffer during final checks.

## Limits

No physical-device, OEM-launcher or older-Android testing was performed. New-install and legacy-default behavior was checked with serialization/default unit tests; the existing emulator installation was preserved. Font checks establish agreement with the official font's shaping data and visual samples, not a scholarly review of every Quranic glyph on every Android shaping-engine version. Animation frame timing and long-run performance were not benchmarked. The native host and accessibility helpers were temporary, outside release sources; this is not a Compose instrumentation test suite.
