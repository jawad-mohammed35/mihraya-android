# Mihraya 1.4.1 QA

Validated on November 11, 2026 using the signed, minified release APK on the Android 15 (API 35) x86_64 emulator.

## Root causes and scope

- Distance, More reciter selection, nested Reading reciter selection, and Reader preferences share `MihrayaSheet`. Its outer glass clip was applied before Material's translated sheet, clipping the moving surface. Decoration now lives inside Material's surface; native sheet state retains full expansion and dragging.
- Removed the configuration-based height estimate and 280 dp minimum. Safe window insets constrain the sheet, while weighted scroll containers reserve space for headings and bottom padding. The same constraints cover verse actions and Tasbih history.
- Material's sheet window chose system-bar icon appearance from the device theme rather than Mihraya's manual appearance. The shared sheet now configures its own window icons and disables contrast scrims.
- Selected navigation icons used primary text color. They now animate to the current accent; the existing accent-colored lens and filled/outlined icon transitions remain.
- OLED previously changed only the main background; raised, glass, translucent overlay, and Material default surfaces remained charcoal or tinted. The palette and shared overlay helper now provide opaque black. Glass borders and selected accent highlights remain; broad glass fills, haze and Home glow cannot lighten OLED base surfaces. Regular Black and Light retain their glass treatments.
- Settings storage, audio/download handling, navigation destinations, Quran data, and library schemas are unchanged. Existing reciter and unit observers already propagate saved choices to Listen and Qibla.

## Emulator checks

- Reproduced the 1.4.0 Distance failure before updating: only the clipped surface and dismiss target were available, with no unit options.
- Installed 1.4.1 over signed 1.4.0 using `adb install -r`, without uninstalling or clearing data. Name, location, appearance, existing bookmark and playback resume entry remained available.
- Reading Preferences opened fully and scrolled through the last translation/download control in portrait, landscape, and at 360 x 640 dp with 1.3 font scale. Also exercised the tall-cutout emulator overlay. Sheet contents stayed above the navigation bar and below the top safe area.
- Distance displayed both choices and the selected radio indicator. Miles immediately produced `5,180 mi to Makkah` from the stored Seoul location; it persisted after force-stop/relaunch. Restored Kilometres afterward.
- More's reciter sheet exposed all 17 entries. Scrolled to and selected the final entry, Hani Ar-Rifai. Selected Alafasy separately and confirmed Listen used that choice after force-stop/relaunch. Restored Ar-Rifai and checked nested Reading settings showed the same preference.
- Listen's existing reciter dropdown opened with a full-width, scrollable list. Nested Reading's reciter sheet also opened correctly.
- Changed all four accents without restarting. Pixel checks on the selected More icon matched dark Champagne `#DCC394`, Emerald `#6CC3A4`, Silver `#CCD2D9`, and Lapis `#93B4E6`. Light Lapis matched `#2F5A9A`. Inactive icons remained neutral.
- Switched Light, regular Black, OLED Black, and System. Settled background pixel checks matched Light `#F5F4F0`, Black `#101114`, and OLED `#000000`. System switched between Light and true black as Android night mode changed, without relaunching.
- Checked the Reader verse-number dialog at the smaller screen size and larger font. Confirmed sheet status/navigation icons remain visible with manual Black while Android is light.
- Source-audited all Material dropdowns, dialogs, sheets, shared settings cards, reader chrome and app navigation surfaces. They use the common appearance palette/overlay colors; decorative artwork and independently configured home-screen widget themes were preserved.

## Limits

No physical device was connected. Other Android versions and OEM window implementations were not exercised. UI checks used ADB accessibility dumps, input and screenshot inspection, not a Compose instrumentation test suite. Animation frame timing was not profiled. No offline audio files were present for an end-to-end download-retention check; that code and storage format were not changed. These checks do not exhaustively exercise every feature.

Reference: [Android's Compose bottom-sheet guidance](https://developer.android.com/develop/ui/compose/components/bottom-sheets).
